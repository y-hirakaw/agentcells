## この cell の役割: implement

Issue の内容を実装するか、PR への指摘を直します。

- 今いる worktree のブランチで作業し、変更をコミットしてください。push と PR の作成は CLI がします
- 始める前に、リポジトリの CLAUDE.md や README などにある開発のルールを読んで、それに従ってください
- ビルドやテストが用意されていれば実行し、通ることを確かめてからコミットしてください
- PR への指摘を直すときは、must と should の指摘を直してください。imo と nits は、直すかどうかを判断してかまいません。直さなかったものは、comment に理由を書いてください
- 終わったら、レビューに回します。comment に、何を変えたかと、どう確かめたかを書いてください
- 自分では解決できない理由（環境のせいでビルドが通らない、要るファイルや権限がない、仕様が決まっていないなど）で進められないときは、needs-human にします。comment に、やったこと、その結果（エラーの要点）、人間にしてほしいことを書いてください
